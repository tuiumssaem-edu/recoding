# 🌱 한걸음 행동노트

> 관찰하고 · 이해하고 · 함께 자라요

학교 현장에서 학생의 행동을 **ABC 기록 · 빈도 기록 · 지속시간 기록**으로 관찰하고, 대시보드와 AI 분석(OpenRouter)으로 패턴 분석 · 중재 조언 · 학부모 상담 팁까지 받아볼 수 있는 Google Apps Script 웹 앱입니다.

## 주요 기능

| 기록법 | ✏️ 기록하기 | 📊 대시보드 · AI |
|---|---|---|
| **ABC 기록** | 선행사건(A) · 행동(B) · 후속결과(C)를 미리 정한 선택지 또는 직접 입력으로 기록 | 일별 추이, 행동·선행사건·후속결과·장소·시간대별 그래프, 자주 나오는 A→B→C 패턴 |
| **빈도 기록** | 표적행동마다 **약 · 중 · 강** 버튼을 누르면 즉시 저장 | 일별 빈도(강도별), 평균 강도 추이, 강도 분포, 시간대·요일별 그래프 |
| **지속시간 기록** | **▶ 시작 / ■ 종료** 버튼으로 측정 (여러 행동 동시 측정, 화면을 닫아도 유지) | 일별 총 지속시간, 행동별 평균·최장 시간, 회당 지속시간 변화 |

- **AI 분석**: 데이터 요약 → 행동 패턴 → 행동 기능 가설 → 중재 조언(예방·대체행동·후속결과·위기 대응) → 학부모 상담 팁 → 다음 관찰 제안
  - ⚡ 간단 / 📚 자세히 모드
  - 모델 선택: 🤖 자동 선택(`openrouter/auto`), 기본 모델, 즐겨찾기, 전체 모델 검색
  - 예비 모델 자동 전환, 결과는 시트의 `AI분석기록` 탭에 자동 저장
  - 학생 이름은 **'대상 학생'으로 익명화**해서 전송
- **구글 시트 저장**: 기록법마다 스프레드시트 1개(`행동기록_ABC`, `행동기록_빈도`, `행동기록_지속시간`)가 자동 생성되고, 그 안에 **학생별 시트 탭**이 만들어집니다.
- **빠른 화면**: 서버 캐시(6시간, 저장·삭제 시 즉시 갱신) + 브라우저 사본으로 다시 열 때 바로 표시

## 파일 구성

| 파일 | 설명 |
|---|---|
| `Code.gs` | 서버 코드 (시트 저장·조회, 캐시, OpenRouter 호출) |
| `Index.html` | 화면 (기록 · 대시보드 · AI 분석 · 설정) |
| `appsscript.json` | 매니페스트 (시간대 Asia/Seoul, 웹 앱 설정) |

## 설치 방법

1. [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만듭니다.
2. `Code.gs` 내용을 붙여넣습니다.
3. **＋ → HTML** 로 파일을 추가하고 이름을 정확히 `Index` 로 지은 뒤 `Index.html` 내용을 붙여넣습니다.
4. ⚙ 프로젝트 설정 → **"appsscript.json 매니페스트 파일 표시"** 를 켜고 `appsscript.json` 내용으로 바꿉니다.
5. 함수 목록에서 `diagnose` 를 골라 **▶ 실행** → 권한을 승인합니다. (실행 로그에서 ✅/❌ 점검 결과 확인)
6. **배포 → 새 배포 → 웹 앱** (다음 사용자로 실행: 나 / 액세스 권한: 나만 권장)
7. 웹 앱 주소로 들어가 **⚙️ 설정**에서 학생 · 표적행동 · OpenRouter API 키를 저장합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 해야 웹 앱에 반영됩니다.

## 문제 해결

- **"서버에 연결하지 못했습니다"**: 브라우저에 구글 계정이 여러 개 로그인되어 있으면 실패할 수 있습니다. 시크릿 창에서 앱을 만든 계정 하나로만 열어 보세요.
- **AI 분석 오류 401 / 402**: API 키 확인 / OpenRouter 크레딧 부족
- **시트를 직접 고쳤는데 반영이 안 됨**: 대시보드의 🔄 버튼을 누르세요.

## 개인정보 안내

- 기록은 배포한 사람의 구글 드라이브에 저장됩니다.
- AI 분석 시 학생 실명은 '대상 학생'으로 바꿔 전송하지만, 메모에 적은 다른 이름 등은 그대로 전송될 수 있으니 메모에는 실명을 적지 않는 것을 권장합니다.
- 빠른 표시를 위해 기록 사본이 사용하는 브라우저(localStorage)에 저장됩니다. 공용 컴퓨터에서는 주의하세요.
- OpenRouter API 키는 Apps Script의 스크립트 속성에만 저장되며 이 저장소에는 포함되어 있지 않습니다.
